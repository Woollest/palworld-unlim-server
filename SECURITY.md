# Security

- Never commit `.env`, `config/discord.env`, `config/admin.env`, world data, backups or logs.
- Keep the Palworld REST API bound to `127.0.0.1` and do not expose TCP port 8212 through Unlim.
- Rotate the Discord Bot token immediately if it is displayed in chat, logs or screenshots.
- Share the Unlim connection key and server password only with intended participants.
- Review official Palworld release notes and create a verified backup before every update.
